# 🚀 الدليل الشامل لمنصة MyBot Studio

**منصة بصرية متطورة لبناء بوتات تيليجرام بدون كتابة أكواد بأسلوب Unreal Engine و n8n**

---

## 🌟 المميزات الرئيسية

* **مساحة عمل بصرية لا نهائية (DAG Canvas):** ربط العقد للأوامر، الرسائل، الشروط (IF/Else)، والمتغيرات البرمجية.
* **معاينة عائمة ومحاكي تيليجرام تفاعلي:** نافذة محادثة واقعية مع أدوات تنسيق النصوص المتقدمة (Bold, Spoiler, Code, Table) والأزرار الملونة (`primary`, `success`, `danger`).
* **تشغيل بدون انقطاع (Zero-Downtime):** فصل محرك تشغيل البوتات عن واجهة التحكم لضمان عمل البوتات 24/7 دون توقف أثناء التحديثات.
* **قاعدة بيانات SQLite بمرونة NoSQL:** تخزين بيانات المستخدمين والمتغيرات داخل حقول JSON سريعة.
* **تجاوز القيود عبر البروكسي و Cloudflare Workers:** تشغيل مستقر حتى في الشبكات المقيدة.

## 🚀 التثبيت والتشغيل

### التثبيت على خوادم Linux VPS
```bash
curl -sSL https://raw.githubusercontent.com/AradPhpProgrammer/mybot/main/install.sh | sudo bash
```

### التشغيل المحلي (Local Mode)
- **Windows:** `start-local.bat`
- **Linux:** `./start-local.sh`
