# 🚀 Документация MyBot Studio

**Платформа для визуального создания Telegram ботов без кода в стиле Unreal Engine и n8n**

---

## 🌟 Основные возможности

* **Визуальный холст DAG:** Построение логики ботов через соединение блоков триггеров, сообщений, условий (IF/Else) и переменных.
* **Интерактивное превью Telegram чата:** Плавающее окно мокапа с поддержкой rich-текста, спойлеров, цитат и цветных кнопок Bot API 9.4+ (`primary`, `success`, `danger`).
* **Встроенный симулятор:** Тестирование команд и кнопок прямо в браузере без смартфона.
* **Zero-Downtime Worker:** Отдельный фоновый процесс ботов обеспечивает 100% аптайм при обновлении панели.
* **NoSQL на SQLite:** Динамические переменные пользователей в JSON полях.
* **Поддержка Cloudflare Worker & Proxy:** Стабильная работа в сетях с ограничениями.

---

## 🚀 Установка

### Автоматическая установка на Linux VPS
```bash
curl -sSL https://raw.githubusercontent.com/AradPhpProgrammer/mybot/main/install.sh | sudo bash
```

### Локальный запуск
- **Windows:** `start-local.bat`
- **Linux:** `./start-local.sh`
