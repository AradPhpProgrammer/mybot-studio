# استودیو مای‌بات (MyBot Studio)

موتور بصری و خودمیزبان (Self-Hosted) برای ساخت، اجرا و مدیریت ربات‌های تلگرام بر پایه گراف جهت‌دار بدون دور (DAG).

استودیو مای‌بات یک محیط کاری مستقل و آفلاین را برای استقرار، زمان‌بندی و نگهداری ربات‌های پرترافیک تلگرام فراهم می‌آورد؛ بدون وابستگی به سرویس‌های ابری شخص ثالث یا ریسک مسدودی حساب.

---

## اصول معماری سیستم

- **ایزولاسیون کامل داده‌های هر ربات**: هر ربات دارای دیتابیس اختصاصی SQLite مستقل (`bot_{id}.db`) است. متغیرهای اجرایی، اطلاعات کاربران و سوابق پیام‌ها کاملاً تفکیک‌شده ذخیره می‌شوند.
- **موتور اجرای قطعی DAG**: فلوهای تعاملی به گراف‌های اجرایی جهت‌دار کامپایل می‌شوند. رویدادها (دستورات، کلیک دکمه‌های شیشه‌ای، کیبوردهای معمولی) از طریق زمان‌بندی رویدادمحور مدیریت می‌شوند.
- **استقلال کامل از زیرساخت‌های خارجی**: توسعه بر پایه FastAPI و Aiogram 3 در سمت سرور، به همراه رابط کاربری Vite و ReactFlow در سمت کلاینت. فونت‌ها و فایل‌های استاتیک کاملاً لوکال و بدون نیاز به اینترنت جهانی بارگذاری می‌شوند.
- **پایداری شبکه در شرایط محدودیت**: پشتیبانی درون‌سازمانی از کلودفلر ورکر (Cloudflare Workers) و تونل‌های HTTP/SOCKS5 برای تضمین اتصال دائمی ربات به سرورهای تلگرام.

## نصب و راه‌اندازی

### نصب خودکار روی سرور مجازی (VPS لینوکس)

با اجرای دستور تک‌خطی زیر روی سرورهای Ubuntu 22.04 به بالا یا Debian 12 (با دسترسی روت):

```bash
bash <(curl -s https://raw.githubusercontent.com/AradPhpProgrammer/mybot-studio/refs/heads/master/install.sh)
```

اسکریپت به صورت خودکار کانتینرهای داکر را پیکربندی کرده، اتصالات امنیتی را اعمال و سرویس را فعال می‌نماید.

## راهنمای مشارکت (Contributing)

برای حفظ پایداری و سلامت معماری نرم‌افزار، مشارکت‌ها با ضوابط زیر پذیرفته می‌شوند:

۱. **گزارش خطا (Bug Report)**: لطفاً با باز کردن یک Issue به همراه مراحل بازتولید خطا، نسخه سیستم و لاگ‌های مربوطه گزارش دهید.  
۲. **درخواست ادغام (Pull Request)**: هر PR باید مستقیماً به یک Issue فعال و تاییدشده ارجاع دهد. افزودن ویژگی‌های خارج از حوزه توافق‌شده پذیرفته نمی‌شود.  
۳. **تست و کیفیت کد**: کلیه تست‌های خودکار بک‌اند (`python backend/tests/run_tests.py`) و بیلد فرانت‌اند باید با موفقیت و بدون هشدار سپری شوند.
